---
name: nada-feature-research
description: Study user-authorized app features and recreate original implementations without copying proprietary assets or bypassing access controls.
---

# Workflow
1. Clarify the feature and whether the target is publicly accessible or user-authorized.
2. Prefer public documentation, visible UI behavior and the user's own source code.
3. Describe observed behavior separately from hypotheses; attach evidence and unknowns.
4. Extract requirements and interaction patterns, not proprietary source, logos, or credentials.
5. Propose an original implementation consistent with the project's design system.
6. Never bypass authentication, license protections, or access restrictions.
7. Verify the result against stated behavior and explain deviations.
